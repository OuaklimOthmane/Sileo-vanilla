Getting started

sileo-vanilla is a small, opinionated toast library for any web page. It is a plain-JavaScript port of Sileo: the same gooey SVG morph and spring physics, without React or any other dependency. It works in plain HTML, Vue, Svelte, Angular, Frappe, server-rendered pages, anything with a DOM.

Installation

With npm

npm install sileo-vanilla
import { toast } from "sileo-vanilla";

toast.success({ title: "Saved" });

That's all: there is no component to mount. The styles are added to the page the first time a toast appears.

With a script tag (no build step)

<script src="https://cdn.jsdelivr.net/npm/sileo-vanilla@0.2.1/dist/sileo-vanilla.umd.min.js"></script>
<script>
  SileoVanilla.toast.success({ title: "Saved" });
</script>

As an ES module from a CDN

<script type="module">
  import { toast } from "https://cdn.jsdelivr.net/npm/sileo-vanilla@0.2.1/+esm";
  toast.info({ title: "Hello" });
</script>

Fire a toast

Each state has its own colour and icon. A toast shows its title in a pill, then unfolds to show the description.

toast.success({ title: "Changes saved", description: "Your changes were saved to the database." });
toast.error({ title: "Something went wrong", description: "We could not save your changes. Try again in a moment." });
toast.warning({ title: "Storage almost full", description: "You have used 95% of your storage." });
toast.info({ title: "New version", description: "Reload the page to get the latest features." });

Action toast

Add a button to let people act on the toast: undo, view, share…

toast.action({
  title: "File uploaded",
  description: "Your file has been uploaded. Share it with your team?",
  button: { title: "Share now", onClick: () => share() },
});

Several buttons, and questions

Give buttons instead of button to put several side by side; primary fills one with the state colour. With autopilot: { expand: 0, collapse: false } the toast opens at once and stays open, even when the mouse leaves: handy for a question that waits for an answer.

const id = toast.warning({
  id: "confirm",
  title: "Delete this file?",
  description: "It will be gone for everyone.",
  duration: 60000,
  autopilot: { expand: 0, collapse: false },
  buttons: [
    { title: "Cancel", onClick: () => toast.dismiss("confirm") },
    { title: "Delete", primary: true, onClick: () => { toast.dismiss("confirm"); remove(); } },
  ],
});

Promise toast

One toast for a slow task: it shows loading while the promise runs, then morphs into success or error. toast.promise returns the original promise, so you can keep chaining.

toast.promise(saveSettings(), {
  loading: { title: "Saving" },
  success: (result) => ({ title: "Saved", description: `${result.count} settings updated.` }),
  error: (err) => ({ title: "Not saved", description: err.message }),
});

Pass action instead of success to end on an action toast (with a button).

Positions

Six positions. Set a default with configure, or choose per toast. Toasts at the top unfold downward, toasts at the bottom unfold upward.

import { configure, toast } from "sileo-vanilla";

configure({ position: "bottom-center" });          // default for every toast
toast.success({ title: "Saved", position: "top-left" }); // or one toast only

toast

Every method returns the toast's id.

MethodWhat it does
toast.success(options)Green check.
toast.error(options)Red cross. Announced at once to screen readers.
toast.warning(options)Amber circle.
toast.info(options)Blue life buoy.
toast.action(options)Blue arrow, usually with a button.
toast.show({ type, ...options })Any state from a variable.
toast.promise(promise, { loading, success, error, action })Loading, then the result. Returns the promise.
toast.dismiss(id?)Closes a toast (the default one without an id).
toast.clear(position?)Removes every toast at once, or those at one position.

sileo is exported too, as the same object, so code written for Sileo reads the same.

configure

Toaster-wide settings. Call it once at start-up (or any time: open toasts follow).

import { configure } from "sileo-vanilla";

configure({
  position: "top-right",          // default position
  offset: 24,                     // px, a CSS length, or { top, right, bottom, left }
  theme: "system",                // "light" | "dark" | "system"
  options: { roundness: 14 },     // defaults for every toast
  injectStyles: true,             // false: link "sileo-vanilla/styles.css" yourself
});

Styling

Change the colour with fill, and add your own classes with className and styles. Every part also has a data attribute you can target in CSS.

toast.warning({ title: "Low battery", description: "Plug the scanner in soon.", fill: "#2b2118" });

toast.success({
  title: "Published",
  styles: { title: "my-title", description: "my-text", button: "my-button" },
});

Useful selectors and variables:

[data-sileo-toast]          /* the toast */
[data-sileo-title]          /* the title in the pill */
[data-sileo-description]    /* the unfolded text */
[data-sileo-button]         /* the action button */
[data-sileo-badge]          /* the round icon */

:root {
  --sileo-width: 350px;
  --sileo-duration: 600ms;
  --sileo-state-success: oklch(0.723 0.219 142.136);
  --sileo-state-error: oklch(0.637 0.237 25.331);
  /* also: loading, warning, info, action */
}

/* Titles are capitalised like Sileo ("Changes Saved"). For languages
   that don't capitalise every word (French, Spanish…): */
[data-sileo-title] { text-transform: none; }

The toast shape is drawn in SVG, so --sileo-width only changes the box, not the drawing (fixed at 350 px, as in Sileo).

Rich content

The title and description take plain text, a DOM node, or { html }. Use any layout: avatars, images, lists, your own components.

toast.info({
  title: "Team update",
  description: {
    html: `<div class="who">
      <span class="faces"><i>AL</i><i>BO</i><i>CH</i></span>
      <span>Alice, Bob and Charlie joined the design team.</span>
    </div>`,
  },
});

Text is always shown as text, never parsed as HTML. Only use { html } with markup you wrote yourself, never with what users typed.

Roundness

Control the corner radius with roundness (default 16). Lower for sharper corners, higher for a rounder pill.

toast.success({ title: "Sharp corners", roundness: 12 });

Performance: higher roundness values increase the SVG blur used for the gooey effect, which costs more to draw. 16 is a good balance between looks and speed.

Themes

"light" (default) gives dark toasts for light pages, "dark" gives light toasts for dark pages, "system" follows the visitor's setting and switches live. The theme button at the top of this page uses it.

configure({ theme: "dark" });

Timing and autopilot

A toast stays 6 s. It unfolds after 150 ms and folds back 2 s before leaving. Hovering any toast pauses every countdown and keeps it open; swiping it up or down closes it.

toast.info({ title: "Long", description: "…", duration: 12000 });

const id = toast.warning({ title: "Offline", description: "Reconnecting…", duration: null });
// later
toast.dismiss(id);

toast.info({ title: "Hover me", description: "…", autopilot: false });
toast.info({ title: "Custom", description: "…", autopilot: { expand: 500, collapse: 3000 } });

Ids and updates

Like Sileo, toasts without an id share one: a new toast morphs the current one instead of piling up. Give ids to show several at once, or to update one toast later.

toast.success({ id: "upload", title: "Uploaded" });
toast.info({ id: "sync", title: "Syncing" });

// update the same toast
toast.info({ id: "job", title: "Step 1 of 2", duration: null });
toast.success({ id: "job", title: "Done" });

Frameworks

It's one function call, so it works the same everywhere. Import it where you need it.

Vue

<script setup>
import { toast } from "sileo-vanilla";
const save = () => toast.promise(api.save(), { loading: { title: "Saving" }, success: { title: "Saved" } });
</script>

<template><button @click="save">Save</button></template>

Svelte

<script>
  import { toast } from "sileo-vanilla";
</script>

<button on:click={() => toast.success({ title: "Saved" })}>Save</button>

Angular

import { toast } from "sileo-vanilla";

@Component({ selector: "app-save", template: `<button (click)="save()">Save</button>` })
export class SaveComponent {
  save() { toast.success({ title: "Saved" }); }
}

Frappe / ERPNext

// in your app's bundle (e.g. public/js/myapp.bundle.js)
import { toast, configure } from "sileo-vanilla";
configure({ theme: "system" });
frappe.provide("myapp");
myapp.toast = toast; // not frappe.toast: Frappe already uses that name for its own alerts

// anywhere in the desk
myapp.toast.success({ title: __("Saved") });

// optional: turn Frappe's own alerts (frappe.show_alert) into toasts too
const colour = { green: "success", orange: "warning", red: "error", blue: "info" };
frappe.show_alert = (m, seconds = 7) => {
  m = typeof m === "string" ? { message: m } : m;
  toast.show({ type: colour[m.indicator] || "info", title: { html: m.message }, duration: seconds * 1000 });
  return $("<div>");
};

Server-rendered pages (SSR)

Importing on the server is safe: nothing touches the DOM until a toast is fired in the browser.

Accessibility

  • Each position is an aria-live="polite" region; errors use role="alert" so they are announced at once.
  • Icons are hidden from screen readers; the title carries the meaning.
  • With "reduce motion" turned on, the toasts appear and change without animation.
  • The action button can be reached with the keyboard and shows a focus ring.
